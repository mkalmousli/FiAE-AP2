# FiAE-AP2

Study site for the IHK AP2 exam (Fachinformatiker Anwendungsentwicklung): EUA, PS, Infrastruktur, WiSO, quizzes, flashcards and crash courses.

Live: https://mkalmousli.github.io/FiAE-AP2/

Plain JavaScript, no build step. Serve the folder with any static server, e.g. `python3 -m http.server`.
